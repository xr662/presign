# 签前：给队友的项目说明

开会时间约 20 分钟，看完这一页就知道要做什么。

## 做的是什么

签前是一个网页，给正在签约的毕业生用。上传录用通知、三方协议、实习协议或劳动合同的照片，网页逐条检查试用期、违约金、社保、竞业限制这些常见问题，每条结论都附上法条原文和计算过程。看完报告，还可以和扮演 HR 的 AI 练习怎么开口要求改条款。

参加的是传智杯 AI Web 赛道，目标省赛，11 月 18 日提交。

## 为什么做这个

很多同学签约前不会逐条看合同，看了也不确定哪条有问题；知道有问题，也不知道怎么跟 HR 说。我们想先确认这个判断对不对，再按真实情况改产品。所以访谈和问卷不是走形式，结果会直接决定"谈判练习"这部分做多少。

## 分工

| 人     | 负责                                                                 | 大约用时 | 时间     |
| ------ | -------------------------------------------------------------------- | -------- | -------- |
| 徐瑞   | 产品设计、全部开发、演示视频、提交                                   |          |          |
| 孙铭阳 | 需求与用户研究：访谈 5~8 人、收集几份合同照片、问卷、请 3 位同学试用 | 4.5 小时 | 11-01 起 |
| 张灿   | 测试与法规核对：核对 15 条规则、拍测试照片、上手测试、抽查评测数据   | 5.5 小时 | 11-01 起 |

两人的分工可以对调，开会时定。

### 孙铭阳

1. 访谈（11-01 ~ 11-04）：按《访谈提纲》找正在秋招、实习或签三方的同学，每人 15 分钟左右，用《访谈记录模板》记下来。
2. 收合同照片（同期）：先把《材料使用说明》发给对方看，对方同意了再收，遮住姓名、身份证号、手机号后发给徐瑞。
3. 问卷（11-01 ~ 11-06）：把《问卷题目》建成问卷星或腾讯问卷，发到班群、年级群，目标 30 份以上。
4. 试用反馈（11-08 之后）：网页能用以后，请访谈过的 3 位同学各用一次，记下哪句看不懂、哪里觉得不准。

### 张灿

1. 规则核对（11-01 ~ 11-05）：按《规则核对表》逐条打开官方链接，看条号、原文、数字有没有抄错。
2. 拍测试照片（11-02 ~ 11-04）：示例合同打印出来后，用两三部手机、在不同光线下拍。拍照清单到时候发。
3. 测试（11-08 之后）：按测试清单在自己的手机和电脑上把主流程走一遍，记下问题。测试清单到时候发。
4. 抽查评测数据（11-09 ~ 11-10）：从程序生成的测试合同里抽 20 份，看标注对不对。
5. 出镜（11-15 前后）：演示视频里谈判练习那段，扮演学生和 AI 对话。

## 交东西

做完的文件发给徐瑞就行，不需要 GitHub 账号。提交到仓库时作者写你本人的名字，评委看提交记录能看到是谁做的。有 GitHub 账号也可以直接在网页上传。

## 两条要求

- 提交材料里只写实际做了的事。访谈了 5 个人就写 5 个，不要凑数。拿到省一会进国赛，国赛现场答辩，评委会问每个人做了什么。
- 别人的合同照片只发给徐瑞，不发群、不存网盘。对方要求删除的，告诉徐瑞马上删。

有问题直接找徐瑞。
