# 合同照片使用说明

收照片之前，先把下面这段发给对方看。对方明确说"同意"以后再收。

---

我们在做一个比赛项目"签前"，帮毕业生在签约前检查合同。想借你的合同或 offer 照片，测试网页能不能把照片里的文字认准、检查结果对不对。

**用来做什么**：只用来测试识别和检查。不会放进比赛提交的材料，也不会给别人看。

**发给我们之前请遮住**：姓名、身份证号、手机号、家庭住址、银行卡号、签名。公司名称可以遮，也可以不遮。用手机自带的涂抹或马赛克就行。遮的时候我们可以帮你看有没有漏的。

**存在哪里**：只存在项目负责人徐瑞的电脑上，不传到代码仓库、网盘或群聊。

**会发给谁**：测试识别时，照片会发给我们用的大模型接口（DeepSeek 模型，经微信 API 平台调用）识别文字。除此之外不发给任何人。

**保存多久**：测试做完就删，最晚 11 月 30 日前删除。

**想撤回**：任何时候跟我说一声，我们当天删掉，不用说原因。
